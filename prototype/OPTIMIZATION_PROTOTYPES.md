# 优化交互原型

本轮原型对应 [优化规划](../OPTIMIZATION_PLAN.md)，用于在正式前端实施前比较布局与核心操作。原有 `/` 下载流程原型保留，新原型使用 `/optimization.html`。

## 预览

```sh
cd prototype # 从仓库根目录执行
npm run dev -- --port 8510 --strictPort
```

在运行该服务的机器上打开：

- [A · 轻盈队列（紧凑管理）](http://localhost:8510/optimization.html?variant=A)
- [B · 运维工作台](http://localhost:8510/optimization.html?variant=B)
- [C · 私人放映室（媒体库优先）](http://localhost:8510/optimization.html?variant=C)

远程访问时，将 `localhost` 替换为开发机可达地址，或使用端口转发。页面顶部可随时切换方案；新标签页打开则从初始演示数据开始。

本轮 A／B／C 是优化方案编号，与早期原型已选定的 B 版名称无关。

## 如何比较

| 方案 | 关注点 | 对比时建议观察 |
| --- | --- | --- |
| A · 紧凑管理 | 延续顶部导航和高密度任务列表 | 同屏信息量、批量操作是否顺手 |
| B · 下载工作台 | 汇总运行情况、突出等待和失败问题 | 是否容易判断卡在哪里、该先处理什么 |
| C · 媒体库优先 | 封面、合集、继续观看 | 是否更容易找到内容、进入连续观看 |

当前决定：用户倾向 C 的媒体库方向，并已确认保留影院／详情两种播放模式，共用同一个播放器。默认影院模式，记住本浏览器上次选择；切换保留播放状态。手机端共用一套观看布局，按需展开详情和查看选集。原型默认进入 C，A／B 继续保留；正式界面尚未修改。

## 播放页原型细化

[统一播放入口](http://localhost:8510/optimization.html?variant=C&watch=1)：首次默认影院模式，之后恢复本浏览器的选择。手机端自动使用统一布局。下面的直达链接用于临时对比指定的桌面模式：

- [影院模式](http://localhost:8510/optimization.html?variant=C&watch=1&player=cinema)：深色独立观看页，突出大画面与右侧选集，适合连续观看。
- [详情模式](http://localhost:8510/optimization.html?variant=C&watch=1&player=detail)：浅色详情页，画面、内容说明、规格和附件信息分区，适合边看边管理。

桌面导航右侧提供“影院／详情”切换，原来的方案评审条已移除。播放区域采用真正的 HTML 视频，提供播放／暂停、进度拖动、音量、倍速、字幕、全屏及选集操作。切换时保持同一个视频实例，保留当前集、播放／暂停、进度、音量、倍速、字幕和自动连播状态。

宽度不超过 820px 时统一为浅色观看页：视频在上，标题在下，通过“选集／详情与附件”切换下方内容；主要操作触控区域至少 44px。手机端不显示影院／详情切换，也不覆盖桌面模式偏好。缩放窗口或横竖屏变化不会重新创建视频。

模式偏好使用独立的原型 localStorage 键保存，刷新、再次打开和新标签页均可恢复；存储不可用时仍可操作。URL 的 `player=cinema/detail` 只用于本次直达预览，不自动覆盖偏好，只有点击模式切换才保存。返回媒体库时清除直达预览参数，下一次打开按记忆选择布局。

返回媒体库后，当前选集与已看标记在本次演示中保留，再打开不会丢失；刷新仍会重置演示观看数据。跨关闭恢复精确播放时间尚未加入该原型，不能将模式记忆视为完整续播实现。

样片由已有且已注明来源的四张原型封面生成：20 秒、720p、H.264、无声，只用于体验播放控制，与片单中的标题内容无关。字幕同样为本地演示字幕。样片位于 `public/preview-media/`，可运行 `python3 generate-review-media.py` 重新生成；图片来源见 [NOTES.md](NOTES.md)。

## 推荐体验顺序

1. **任务**：选择任务，尝试暂停／恢复；查看网络等待和附件待补的处理入口。
2. **大合集**：加载下一批，搜索并选择条目，解析所选，再确认入队；取消确认时检查选择是否保留。
3. **订阅**：切换提示与自动入队模式，手动检查更新，暂停订阅。
4. **空间**：比较两个文件系统，勾选待清理内容，打开确认并取消，再尝试确认清理。
5. **媒体库**：打开播放器，对比影院／详情模式，实际播放、拖动进度、切换字幕和选集，体验自动连播。
6. **偏好设置**：调整重试次数、空间阈值和附件策略，保存并查看反馈。

三套方案共用操作逻辑；同一页面内切换方案时保留状态，使用“重置演示”回到初始演示数据，已保存的播放布局偏好保留。

## 演示边界

- 数据、容量、进度和订阅结果均为虚构，仅保存在浏览器内存，刷新复位。只有播放布局偏好保存在本浏览器。
- 不调用业务 API，不连接 B 站，不操作真实下载任务、文件、数据库或登录凭据。
- 播放器播放本地生成的无声样片，不请求 B 站媒体；倒计时与恢复结果用于呈现界面，不代表后台调度已经实现。
- 第一轮着重比较布局和常用流程。分页中断、权限失效、重启恢复、全部跨页选择等边界交互，在对应功能实施前继续细化。
- 示范默认值不代表用户已经选定重试次数、空间阈值或附件完成策略。

## 构建

```sh
npm run build
```

Vite 同时构建原有 `index.html` 和新增 `optimization.html`，产物只属于原型目录，不进入正式 `frontend`。
